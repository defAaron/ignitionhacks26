# API

- Some components have an "API user."
- Hook an API to a component → it should be very easy to edit the code for how that component uses the API.
- Maybe a pseudo API editor.
- A button can link to a database or an external site via a line.
- The line can hold code: a reference, or run a quick API call.
- The frame the component lives in can carry other info, e.g. authorization.
