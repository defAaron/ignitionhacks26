## Demo that wins the theme

Judges should feel **art** first, then **tech**:

1. Blank paper
2. Sketch a page (navbar `n`, button `b` + "Login", a shaded shape)
3. Enter — watercolor blooms in, ink shakes away
4. Frame — working website, download the HTML (Seal the page first; Frame the plane if you have more than one)

One sentence if asked how it works: *Gemini describes the ink, our 2B FreeSolo fine-tune decides the command, geometry always comes from the strokes.*
